# Initiative Labs

Production website for Initiative Labs — an open-source lab for physical
intelligence (embodied AI, electronics, robotics). Built with Next.js (App
Router, TypeScript) and Tailwind CSS.

Content — projects and lab notebook entries — lives as markdown files with
frontmatter in the repo. No CMS, no database.

## Development

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

More to come as the site is built out sprint by sprint.
